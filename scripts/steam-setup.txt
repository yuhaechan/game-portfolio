Steam 플레이 이력 연결

이 파일은 최신 공개 화면이 있는 pages-upload 프로젝트 기준입니다.
상위 폴더의 이전 package:pages 명령으로 이 프로젝트를 덮어쓰지 마세요.

1. Steam 프로필의 게임 세부 정보가 공개되어 있어야 합니다.
   플레이시간을 별도로 비공개로 설정했다면 해당 설정도 확인하세요.

2. Steam Web API 키와 SteamID64를 비공개로 설정합니다.
   키는 채팅, content JSON, NEXT_PUBLIC_ 환경변수에 넣지 않습니다.
   Steam 비밀번호나 Steam Guard 코드는 필요하지 않습니다.

3. 로컬 .env.steam.local 파일에 아래 환경변수를 설정합니다.
   STEAM_WEB_API_KEY=발급받은 키
   STEAM_ID=17자리 SteamID64
   이 파일은 .gitignore에 의해 제외됩니다.

4. 프로젝트 폴더에서 목록을 가져옵니다 (Node 22 이상).
   node --env-file=.env.steam.local scripts/sync-steam.mjs --catalog
   목록은 Git에 제외된 .local/steam-library.json에 저장됩니다.

5. 홈페이지에 보일 게임의 appId만 content/steam-selection.json의 appIds에
   원하는 순서로 넣습니다. 기본값은 빈 목록이며 임의로 게임을 공개하지 않습니다.

6. 선택한 게임을 갱신합니다.
   node --env-file=.env.steam.local scripts/sync-steam.mjs
   선택한 게임의 이름과 누적 시간(분), 갱신일만 content/steam-history.json에
   저장됩니다. 화면은 시간을 시간 단위로 표시합니다.

7. GitHub에 반영하기 전 로컬에서 확인하고 사용자 승인을 받습니다.
   GitHub 저장소의 Actions secrets에 STEAM_WEB_API_KEY, STEAM_ID를
   설정하면 다음 게시 빌드부터 선택한 게임을 Steam에서 다시 조회합니다.
   스케줄은 설정하지 않았습니다. 갱신은 게시 또는 수동 workflow 실행 시입니다.

오류가 나면 새 데이터로 덮어쓰지 않습니다. 비공개 프로필, 시간 비공개,
선택한 게임 누락 등의 경우 공개 설정과 선택 목록을 확인하세요.
외부 요청 오류 메시지에 API 키나 요청 주소를 기록하지 않습니다.
